
# QueueLess

A smart queue management system that allows customers to join virtual queues and track their waiting time while staff manage queues efficiently.

## Development Server

To start the local development server, run:

```bash
ng serve
```

Open your browser and navigate to `http://localhost:4200/`.

The application will automatically reload whenever you modify any source files.

## Building

To build the project, run:

```bash
ng build
```

The build artifacts will be stored in the `dist/` directory.

## Running Tests

To execute unit tests, run:

```bash
ng test
```
